Política de Privacidade — PcBarato

Última atualização: 28/08/2026 — pcbarato.vercel.app

PcBarato é um comparador de preços de hardware. Esta política explica como tratamos dados ao integrar com Mercado Livre e outras lojas via APIs de afiliados.

1. Dados coletados

Coletamos apenas dados públicos de ofertas (título, preço, imagem, disponibilidade) via APIs oficiais. Não coletamos dados sensíveis nem armazenamos cartões. Para o Mercado Livre, armazenamos apenas access_token e refresh_token do app 3918756121989781 para buscas autenticadas.

2. Uso dos dados

Usamos ofertas exclusivamente pra comparação e geração de links afiliados (ex: pcbarato05-20 Amazon, Pcbarata AliExpress, awc=115463 Awin/Gigantec). Não vendemos dados.

3. Cookies e rastreamento

Usamos cookies de afiliados das lojas parceiras (30 dias Last Click em alguns programas). Aviso no rodapé: “Alguns links são de afiliados — não custa nada a mais”.

4. Compartilhamento

Compartilhamos apenas o necessário com as APIs das lojas pra obter ofertas. Não repassamos tokens a terceiros.

5. Seus direitos (LGPD)

Você pode pedir exclusão de dados de contato via Telegram @AgentPcBbot ou pedrolpes6@hotmail.com.
