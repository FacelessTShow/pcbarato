Política de Privacidade — PcBarato

Última atualização: 28/08/2026 — PcBarato (pcbarato.vercel.app)

O PcBarato é um comparador de preços de hardware. Esta política explica como tratamos dados ao integrar com o Mercado Livre e outras lojas via APIs de afiliados.

1. Dados coletados

Coletamos apenas dados públicos de ofertas (título, preço, imagem, disponibilidade) via APIs oficiais. Não coletamos dados pessoais sensíveis nem armazenamos cartões. Para a integração com o Mercado Livre, armazenamos apenas access_token e refresh_token do aplicativo 3918756121989781 para chamadas autenticadas de busca.

2. Uso dos dados

Os dados de ofertas são usados exclusivamente para comparação de preços e geração de links de afiliado com rastreamento (ex: pcbarato05-20 Amazon, Pcbarata AliExpress, awc=115463 Awin/Gigantec). Não vendemos dados.

3. Cookies e rastreamento

Utilizamos cookies de afiliados das lojas parceiras (30 dias Last Click em alguns programas). O usuário é informado no rodapé: "Alguns links são de afiliados — não custa nada a mais".

4. Compartilhamento

Compartilhamos apenas o necessário com as APIs das lojas para obter ofertas. Não compartilhamos tokens com terceiros.
